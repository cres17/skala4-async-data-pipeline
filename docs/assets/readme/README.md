# README 도식과 기술 아이콘

`architecture.svg`와 `architecture-dark.svg`는 저장소의 주요 구성과 데이터 흐름을 설명합니다. 전체 캔버스는 투명하며 밝은 테마·어두운 테마를 별도 파일로 제공합니다.

`tech-stack.svg`와 `tech-stack-dark.svg`는 기술 아이콘을 같은 크기와 간격으로 정렬한 이미지입니다. 세부 버전·사용처와 구현 범위는 루트 README의 기술 스택 표를 기준으로 확인합니다.

브랜드 아이콘은 [Simple Icons](https://github.com/simple-icons/simple-icons)의 SVG를 사용했습니다. OpenAI 로고는 해당 프로젝트의 14.0.0 버전, 나머지는 작성 시점 develop의 아이콘을 포함했습니다. 원본 아이콘은 CC0로 배포되지만 브랜드명·상표 권리는 각 소유자에게 있습니다. 파일·기기·API·상태 등의 일반 기호는 이 문서용 벡터 도형입니다.

변경 시에는 루트 README의 설명과 노드·연결을 함께 수정하고 두 테마의 가독성을 확인합니다. SVG는 외부 이미지·스크립트·네트워크 로딩에 의존하지 않습니다.
